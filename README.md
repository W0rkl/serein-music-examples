# музыка / дизайн-проект

интерактивный музыкальный пример для **телефона и пк**. общая система сохраняет понравившиеся ys text, ysmusic headline, чёрные панели и компактные списки. главная теперь самостоятельная: большая объёмная клавиша случайного выбора с раскрывающимися обложками, без копии «моей волны».

## что можно попробовать

случайный выбор, витрина «что послушать», поиск, коллекция, альбом, артист, плейлист и отдельный профиль. мини-плеер и полный плеер, очередь, лайки, сохранение артистов, перестановка плейлистов, светлая/тёмная/системная тема и уменьшение движения. в коллекции → плейлисты → «изменить порядок» есть перетаскивание, кнопки и alt+стрелки.

шрифты и базовая геометрия опираются на обследованную веб-версию яндекс музыки; главный экран и профиль разработаны отдельно. это независимое демо, а не официальный клиент яндекса. персональные экраны аккаунта и установленное нативное приложение не проверялись. на месте рекламной области показан текущий трек. звук — синтезированные 45-секундные фрагменты, исполнители вымышлены.

случайная клавиша каждый раз выбирает новый трек из выбранной группы; пауза продолжает тот же трек. никнейм и цвет аватара в профиле сохраняются только в этом браузере. счётчики профиля показывают текущую коллекцию.

## продолжить работу

прочитать `DESIGN.md` и `MOTION-MAP.md`, затем использовать существующие компоненты и токены. интерфейс приложения находится в `src/App.tsx`, общая система — в `src/yandex-reference.css`, собственные главная и профиль — в `src/listen.css` и `src/components/ui/{shuffle-launcher,local-profile}.tsx`, прежние адаптации — в `src/components/ui/selected-motion.tsx`. не возвращать кремовую палитру, serif и журнальный hero прежней версии.

## запуск

из этой папки:

```sh
npm install
npm run dev
```

```sh
npm run typecheck
npm test
npm run build
npm run export:preview
```

`dist/` — production-сборка. `docs/` — опубликованная сборка github pages. `preview/standalone.html` содержит код и стили в одном файле; изображения и официальные шрифты загружаются из интернета. это не полностью офлайн-пакет.
