# музыка / дизайн-проект

готовый интерактивный дизайн-пример по текущему интерфейсу яндекс музыки: **телефон и пк**. проверенный визуальный образец открыт 14 октября 2026; использованы ys text и ysmusic headline, чёрные панели, жёлтый акцент, компактные списки и единая навигация.

## что можно попробовать

моя волна, витрина «что послушать», поиск, коллекция, альбом, артист, плейлист. мини-плеер и полный плеер, очередь, лайки, сохранение артистов, перестановка плейлистов, светлая/тёмная/системная тема и уменьшение движения. в коллекции → плейлисты → «изменить порядок» есть перетаскивание, кнопки и alt+стрелки.

интерфейс воспроизводит правила и размеры обследованной веб-версии, включая мобильную компоновку. это независимое демо, а не официальный клиент яндекса. персональные экраны аккаунта и установленное нативное приложение не проверялись. на месте рекламной области показан текущий трек. звук — синтезированные 45-секундные фрагменты, исполнители вымышлены.

## продолжить работу

прочитать `DESIGN.md` и `MOTION-MAP.md`, затем использовать существующие компоненты и токены. интерфейс приложения находится в `src/App.tsx`, эталонные стили — в `src/yandex-reference.css`, адаптации выбранных компонентов — в `src/components/ui/selected-motion.tsx`. не возвращать кремовую палитру, serif и журнальный hero прежней версии.

## запуск

из этой папки:

```sh
npm install
npm run dev
```

```sh
npm run typecheck
npm test
npm run build
npm run export:preview
```

`dist/` — production-сборка. `docs/` — опубликованная сборка github pages. `preview/standalone.html` содержит код и стили в одном файле; изображения и официальные шрифты загружаются из интернета. это не полностью офлайн-пакет.

## проверка и границы

14 октября 2026: typecheck, тесты модели, production build и экспорт прошли. форматирование проверено существующим oxfmt. фактические браузерные сценарии и ограничения зафиксированы в [отчёте](VERIFICATION.md); исходные и сравнительные снимки — в `design-reference/`.
